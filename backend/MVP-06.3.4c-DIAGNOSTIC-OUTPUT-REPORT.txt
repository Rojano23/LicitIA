  [SECTION 3] DISCOVERED CANDIDATES (all fields)
    └─ For each discovered:
       - domain, description (full model output)
       - evidence_excerpt (full extracted text)
       - detail_type, normalized_label, confidence
       - quantity_raw, unit_raw

    └─ Missing expected obligation indices

    └─ Mixed-domain issues (if any)

    └─ Case-level validation errors
